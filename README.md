## Featured Projects

### 🎙️ [Voice AI Analytics Platform](https://github.com/bhanumad/project)
> Industry Partner: Heya AI × RMIT University · 2026

Full-stack audio intelligence platform extracting acoustic and behavioural signals from raw call recordings and making them queryable through a natural language interface.

- GPU-accelerated audio pipeline using CUDA/PyTorch + pyannote.audio
- 9-table PostgreSQL schema with SQLAlchemy ORM — 139,663 word-level records
- LangChain RAG agent with dual-path routing (SQL + Chroma vector search)
- FastAPI backend with multi-tenant data isolation via header authentication
- Live Chart.js dashboard with 8 visualisation components

`Python` `FastAPI` `PostgreSQL` `LangChain` `RAG` `PyTorch` `CUDA` `Chroma` `librosa` `Groq`

### ☁️ [AWS Music Subscription Platform](https://github.com/bhanumad/music_app)
> RMIT Cloud Computing COSC2626 · Solo Developer · 2026

Same application built and benchmarked across three independent AWS architectures — EC2, ECS Fargate, and Lambda. Delivered a comparative analysis recommending Lambda as the optimal production solution.

- Caught 4 DynamoDB edge cases causing silent data loss — redesigned schema with composite key
- Implemented Global Secondary Index + Local Secondary Index for efficient query patterns
- Dockerised Flask app pushed to ECR and deployed via ECS Fargate
- Genuine RESTful API with correct HTTP method mapping across all three architectures

`Python` `Flask` `React 18` `DynamoDB` `AWS Lambda` `EC2` `ECS Fargate` `Docker` `API Gateway` `Nginx`
